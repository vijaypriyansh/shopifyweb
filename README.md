This is a Shopify Online Store 2.0 starter theme with an energetic sports-nutrition storefront layout inspired by the public SparkFusion brand category. It is not a copy of SparkFusion's proprietary theme or a guarantee of matching its current storefront pixel-for-pixel.

The home page is pre-populated with editable hero, trust points, shop-by-goal tiles, featured products, brand statement, and newsletter sections. Configure these under Shopify Admin → Online Store → Themes → Customize. Add your logo and image assets; choose your own store's collections in the editor. The products shown are whatever products already exist in your Shopify store—this theme does not import or create products, prices, inventory, customer reviews, or product photography. Product tags `best-seller`, `Bestseller`, `new`, and `New` control optional badges. Reviews are not fabricated.

Install by downloading this branch ZIP from GitHub and uploading it under Shopify Admin → Online Store → Themes → Add theme → Upload ZIP file. Then set up products, collections, navigation, policies, and brand imagery. Run `shopify theme check` and test in a development store before publishing.
